# adrobot
Скопировать и выполнить в терминале:
```bash
curl -O https://raw.githubusercontent.com/MarkTsarkov/adrobot/main/speed_test.py && python3 speed_test.py
```
Будет скачан и запущен скрипт обращающийся на дефолтный адрес ```DEFAULT_URL = "https://fastly.picsum.photos/id/545/5000/5000.jpg?hmac=g9yRBtkYttctwBksi8hIIdmvVD_X31keNm1_jfm5hkE"```

Для запуска скрипта со своим URL нужно выполнить 
```
curl -O https://raw.githubusercontent.com/MarkTsarkov/adrobot/main/speed_test.py
```
А затем 
```
python3 speed_test.py [URL]
```
